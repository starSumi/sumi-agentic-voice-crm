# Changelog

## [0.1.0] - 2026-08-14

- Added contract-first `/v1/ask` text/audio reference server.
- Added mock ASR, intent/entity extraction, CRM command idempotency, review task and TTS asset contract.
- Added OpenAPI 3.1, event envelope, PostgreSQL target migration, audit/lifecycle/security/release documentation.
- Added node:test contract suite, repository checks, reproducible build manifest, Dockerfile and CI workflow.
- Added an Astro/Starlight documentation site generated directly from `docs/`, with English and Simplified Chinese core guides and light/dark/automatic themes.
- Added a bounded Sumi Docs MCP projection with stable document identity, route metadata, converted OpenAPI JSON, and cross-project protocol verification.
- Added versioned `.agent/` governance while isolating machine-local agent state and generated evidence from Git and delivery contexts.
- Added maintainer ownership, a reviewed continuity cursor, external session snapshots, and a least-privilege CI operations workflow with deterministic incident reconciliation.

This is a pre-alpha development baseline, not a release candidate. Real provider quality, production identity, infrastructure, and SLO evidence remain open development and release gates.
