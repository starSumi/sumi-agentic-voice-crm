# C0 — scope and evidence freeze

**Gate owner:** supervisor
**Approvers:** commander, architect, reviewer

## Checklist

- [ ] Product outcome, tenant model, locales, risk classes and retention are approved.
- [ ] Target owner, remote, branch, commit and dirty state are recorded.
- [ ] Saathi/Northstar sources are pinned and the non-copying declaration is reviewed.
- [ ] Source-confirmed, runtime-observed, inferred and unknown facts are separated.
- [ ] Exclusions, rollback owner, incident contact and evidence retention are named.

## Required evidence

Scope brief, source index, manifest update, decision log and reviewer sign-off.

## Failure / rollback

If source identity or scope changes, freeze the current round and open a new
attempt; never silently move the evidence basis.
