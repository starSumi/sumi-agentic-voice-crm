# C1 — contract freeze

**Gate owner:** contract-owner
**Approvers:** domain-owner, security-owner, reviewer

## Checklist

- [ ] OpenAPI 3.1, event registry and schemas parse in CI.
- [ ] `/v1/ask` text and audio variants, multipart metadata and TTS contract agree with runtime.
- [ ] Error status, code and retryability mappings are complete.
- [ ] Tenant, actor, idempotency and correlation headers are explicit.
- [ ] Postman examples and compatibility/deprecation policy are current.

## Required evidence

Schema parser output, contract tests, Postman import/export check and diff review.

## Failure / rollback

Use additive fields or a versioned endpoint/event. Breaking changes require a
new contract version and migration window.
