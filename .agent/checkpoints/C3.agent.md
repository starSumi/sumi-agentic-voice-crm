# C3 — media and provider readiness

**Gate owner:** asr-owner / tts-owner
**Approvers:** agent-runtime-owner, security-owner, reviewer

## Checklist

- [ ] ASR checks size, magic bytes, codec, duration, silence and locale capability.
- [ ] TTS checks text length, locale/voice capability, MIME, duration and expiry.
- [ ] Provider timeout, retry budget, circuit breaker and fallback are tested.
- [ ] Media is private, encrypted, malware-scanned and referenced by expiring URLs.
- [ ] Secrets are externalized and never appear in logs, fixtures or artifacts.

## Required evidence

Normal voice, empty/no-source, malformed/oversize media, unsupported locale,
provider-down and TTS-to-text fallback test records.

## Failure / rollback

Quarantine media or disable the provider feature flag; ASR may not invent text,
and TTS failure must preserve the text answer.
