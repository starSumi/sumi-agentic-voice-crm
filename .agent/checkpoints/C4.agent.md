# C4 — observability and resilience

**Gate owner:** sre-owner
**Approvers:** agent-runtime-owner, release-owner, reviewer

## Checklist

- [ ] Request, trace, event and aggregate IDs correlate without raw PII.
- [ ] P50/P95/P99, error, confidence, review age, queue lag and provider metrics exist.
- [ ] Restart/drain, duplicate delivery, provider outage, dead-letter and restore drills pass.
- [ ] Alerts have thresholds, runbooks and an on-call owner.
- [ ] Replay is bounded, authorized and idempotent.

## Required evidence

Trace screenshots/export, metric snapshots, fault-injection logs, restore report
and incident timeline.

## Failure / rollback

Remove readiness, pause consumers and preserve leases/outbox/review/media for
operator disposition.
