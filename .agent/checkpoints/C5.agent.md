# C5 — security and privacy

**Gate owner:** security-owner
**Approvers:** data-owner, sre-owner, reviewer

## Checklist

- [ ] OIDC/JWT claims bind actor to tenant; RBAC, CORS and rate limits are verified.
- [ ] Prompt injection and tool allowlist fixtures cannot cross policy boundaries.
- [ ] Media traversal, decompression, MIME spoofing, malware and SSRF tests pass.
- [ ] Retention, deletion and legal hold behavior is evidenced.
- [ ] SAST, SCA, secret scan, SBOM and provenance reports are attached.

## Required evidence

Security test report, findings/waivers, data-flow review, deletion/restore drill
and dependency/provenance artifacts.

## Failure / rollback

Block release for critical/high findings. A waiver must be explicit, time-bound,
owned and paired with a compensating control.
