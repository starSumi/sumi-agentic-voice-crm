# P7 — release and operations

**Owner:** release-owner + sre-owner + commander
**Purpose:** build a reproducible artifact, migrate safely, deploy progressively
and establish on-call ownership.

**Outputs:** image digest, lock hash, content-addressed runtime manifest,
SBOM/provenance/signature, migration plan, canary evidence, dashboards,
operator handoff, communication and rollback drill. `release-candidate.yml`
is the only workflow permitted to assemble an attested candidate, and it is
manual, exact-commit checked and environment-gated.

**Exit criteria:** C6 is approved by product, security, platform and operations;
the production decision is explicit (`approved`, `held` or `rejected`).

**Rollback:** canary halt and application image rollback; retain previous
contract-compatible image and complete cleanup migrations only after observation.
