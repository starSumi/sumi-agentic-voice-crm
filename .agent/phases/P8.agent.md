# P8 — closeout and learning

**Owner:** supervisor + reviewer
**Purpose:** close tasks without losing evidence, record deviations, update
traceability and feed reusable workflow improvements back to governance.

**Outputs:** final release record, lessons learned, supersession links, evidence
retention decision, open follow-up tasks and clean handoff.

**Exit criteria:** all checkpoint states are reconciled, the repository is clean
or unrelated dirt is explicitly handed off, and no open task is ownerless.

**Rollback:** reopen the affected checkpoint with a new attempt ID; preserve the
closed evidence and link the new corrective run.
