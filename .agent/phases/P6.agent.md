# P6 — verification, security and quality

**Owner:** qa-owner + security-owner + reviewer
**Purpose:** prove behavior and safety across contract, unit, integration, E2E,
fault, load, privacy, supply-chain and prompt-injection dimensions.

**Outputs:** test matrix, fixtures, security findings/waivers, performance
budgets, SBOM/secret scan/SAST reports and residual-risk register.

**Exit criteria:** C5 passes and C6 evidence bundle is reviewable; all waivers
name an owner, expiry, compensating control and rollback.

**Rollback:** block promotion, quarantine the release candidate and open a
bounded remediation task; never waive a missing security control implicitly.
