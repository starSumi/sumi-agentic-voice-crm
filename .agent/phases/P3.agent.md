# P3 — service and provider implementation

**Owner:** agent-runtime-owner + asr-owner + tts-owner
**Purpose:** implement the provider-neutral ask pipeline and independently
replaceable ASR, intent, CRM-query, policy and TTS adapters.

**Outputs:** service code, timeouts/retries/circuit policy, capability health,
mock providers, media validation, prompt/tool version records and API wiring.

**Exit criteria:** C3 passes with normal voice, silence, no source, unsupported
codec/locale, provider timeout and TTS fallback evidence.

**Rollback:** feature-flag provider version; degrade TTS to text; route intent
to the previous schema/model; preserve input media and interaction records.
