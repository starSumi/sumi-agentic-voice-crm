# P0 — discover and scope

**Owner:** discover → supervisor
**Purpose:** freeze the problem, actors, constraints, inspiration evidence and
unknown runtime facts before design work starts.

**Inputs:** user outcome, target checkout identity, Saathi/Northstar pinned
source, current environment and risk appetite.

**Outputs:** scope brief, source index, ownership map, threat/unknown register,
non-copying boundary and initial delegation packets.

**Exit criteria:** C0 accepted; scope has explicit exclusions, every claim is
classified, source checkout states are recorded, and no credential or external
checkout is modified.

**Rollback:** supersede the scope record with a new dated record; preserve the
original evidence package.
