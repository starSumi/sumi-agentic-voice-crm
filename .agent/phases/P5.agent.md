# P5 — integration, observability and resilience

**Owner:** sre-owner + agent-runtime-owner
**Purpose:** connect media storage, event relay, workers, dashboards, tracing,
dead letters, replay and graceful shutdown/recovery.

**Outputs:** OpenTelemetry traces, redacted logs, metrics/SLOs, queue leases,
retry/dead-letter policies, restore/replay drills and incident runbooks.

**Exit criteria:** C4 passes; restart, duplicate delivery, provider-down,
outbox lag, dead-letter and restore drills have timestamped evidence.

**Rollback:** pause consumers, preserve outbox/review/media records, replay by
original idempotency key after the fault is understood.
